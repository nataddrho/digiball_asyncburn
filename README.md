# AsyncBurn
Another tool for the Aramith DigiBall. AsyncBurn generates DigiBall overlays from imported data and burns them into a provided video asynchronously via post-processing. Automatically save shot data using the DigiBall app on your mobile device and simultaneously recording a video from any other device or camera. When finished, copy both the data and the video to a computer with Python and ffmpeg unstalled. Run the Python script asyncburn.py and generate a bat file. Run the bat file to add overlays to your video.

This is experimental. Clock drift between two asynchronous devices may be a problem for long videos.

See www.digiball.net for more information."# digiball_asyncburn"
